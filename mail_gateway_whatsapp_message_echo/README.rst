When the same phone number is used both from the WhatsApp Cloud API and
from the WhatsApp Business app, the messages your agents write from the
app are not stored in Odoo, so only half of the conversation is visible
on the channel.

This module records those replies on the corresponding WhatsApp channel,
so the conversation history in Odoo matches the one the customer sees.

Configuration
=============

Meta only pushes those messages when the phone number is registered in
coexistence mode, that is, shared between the Cloud API and the WhatsApp
Business app.

- Access `Facebook Apps
  website <https://developers.facebook.com/apps/>`__
- Access your App then Whatsapp > Configuration
- Administer the Webhook and activate the ``smb_message_echoes`` field,
  next to the ``messages`` one you already use for the gateway

Echoes are only recorded, they are never sent back to the customer.

Known issues / Roadmap
======================

Meta does not report which agent wrote the message from the WhatsApp
Business app, so every echo is logged with the company partner as
author.

The historical conversations are not recovered: Meta only offers them
during the coexistence onboarding, through the ``history`` webhook
field, which is not supported yet.
