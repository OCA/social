This module adds the **WhatsApp** channel to *Mail Message Import*
(``mail_message_import``), through the WhatsApp gateway of
``mail_gateway_whatsapp``: the senders write or forward their messages
to a WhatsApp number, and each message becomes a received message,
identified, grouped and processed as the messages of every other
channel.

- A **receiving channel** of type *WhatsApp* is a number of Meta (its
  *Phone Number ID*) received by a WhatsApp gateway.
- The **authorized addresses** of type *WhatsApp* are phones, compared
  in international format as WhatsApp sends them: ``+34 600 000 000``,
  ``0034600000000`` and, in a Spanish company, ``600 000 000`` are the
  same phone.
- Each message is a **received message**, with its text, a copy of its
  files and a link to the Discuss chat of the gateway.

The gateway keeps working as usual: it checks the signature of the
webhooks, posts the messages in its Discuss chats and downloads their
files.

Configuration
=============

1. Configure a WhatsApp gateway in *Message Import > Configuration >
   Gateways* (administrators only), as explained in
   ``mail_gateway_whatsapp``: the access token, the app secret (*Webhook
   Secret*), the verify token (*Whatsapp Security Key*), the webhook key
   and the *Whatsapp From Phone*. Set the webhook in Meta with the
   webhook URL of the gateway and verify it.
2. In *Message Import > Configuration > Receiving channels*, create a
   channel:

   - *Channel*: **WhatsApp**.
   - *Gateway*: the WhatsApp gateway.
   - *Meta Phone Number ID*: the identifier of the number in Meta
     (WhatsApp Manager > API setup). The *Whatsapp From Phone* of the
     gateway is proposed.
   - *Phone Number*: the number the senders write to, to show it.

3. In each sender, tab *Phones and email addresses*, add the phones it
   sends from, with the channel *WhatsApp*. A new phone can also be
   authorized from its first message, in *Message Import > To review >
   Unknown senders*.

The channel tells what is missing in the gateway, and is *Pending
verification* until the webhook is verified from Meta.

Usage
=====

- The messages appear in *Message Import > Received > Received messages*
  with the channel *WhatsApp*, a link to their Discuss chat and the
  original data of Meta. The filter *WhatsApp* shows only them.
- Only the messages sent to the number of a receiving channel are
  received; the other numbers of the gateway keep working as before.
- A message that Meta delivers again (same ``wamid``) is received once,
  and the gateway does not post it again in its chat.
- The reactions and the stickers are recorded but not processed. The
  text of the buttons, lists, locations and contacts is kept as the text
  of the message.
- The module sends no message.
