This module allows users to set their default chatter visibility
preference (Show or Hide) in Odoo form views.

.. contents::
   :local:

Configuration
=============

To configure this module

1. Click on your **user profile** (top-right corner of Odoo).
2. Select **Preferences** / **My Profile** from the drop-down menu.
3. In the **Preferences** screen, find the field **Default Chatter
   Visibility**.
4. Select one of the options:

   -  **Show** — to display chatter by default on all forms.
   -  **Hide** — to hide chatter by default on all forms.

5. Click **Save** to apply the changes.

Usage
=====

To configure the default visibility of the Chatter in Odoo:

1. Click your **user profile** (top-right corner).

2. Select **Preferences**.

3. In the **Preferences / My Profile** screen, set **Default Chatter
   Visibility** to either **Show** or **Hide**.

4. Click **Save** to apply your changes.

5. Open any form view (e.g., Sales Order, Contact, Invoice):

   -  **Show** → Chatter is visible by default.
   -  **Hide** → Chatter is hidden by default.

6. You can still toggle the Chatter manually using the **Show / Hide**
   buttons on the form.
