- Go to **Marketing \> Campaigns**.
- Open any campaign to see the *Start Date* and *End Date* fields.
- Use the **Running**, **Upcoming**, or **Finished** filters in the search
  bar to filter campaigns by their current date state.
- A campaign with no *Start Date* set is considered **Running** (as long as
  it is not yet finished), since there is no defined start constraint. Only
  campaigns with an explicit future *Start Date* are considered **Upcoming**.
