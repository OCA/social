This module adds a ``last_message_date`` field to every model with a chatter
(``mail.thread``): the datetime of the latest message on the record.

The field is computed from the messages when it is read, and is not stored, so
posting a message does not write to the record. It can be used in search domains,
filters and timed automated actions, but not to sort or group records in list views.
Only internal users can see it.

Configuration
=============

To choose which messages count, go to *Settings > Technical > Parameters > System
Parameters* (in developer mode) and set ``mail_last_message_date.message_types`` to a
comma-separated list of message types:

* ``email``: incoming emails. Emails sent from a template outside the chatter, for
  example by a *Send Email* server action, also count; if the template has *Auto
  Delete* checked (the default), they stop counting once they are sent.
* ``comment``: messages and notes posted in the chatter
* ``notification``: system notifications, such as record creation and tracked field
  changes
* ``auto_comment``: emails sent automatically when a tracked field such as the stage
  changes

By default, ``email`` and ``comment`` count. If the parameter has no valid type, no
message counts.

Usage
=====

Use *Last Message Date* in a filter, or as the trigger date of a timed automated
action, for example to act on records that have had no new message for 7 days.
Records without any counted message have no *Last Message Date*, so such an action
never acts on them.

To fix the message types for a model regardless of the system parameter, override
``_get_tracked_message_types()``:

.. code-block:: python

   from odoo import models

   class PurchaseOrder(models.Model):
       _inherit = "purchase.order"

       def _get_tracked_message_types(self):
           return ["email"]
