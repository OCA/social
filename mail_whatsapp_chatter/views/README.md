# Mail WhatsApp Chatter

[![OCA](https://img.shields.io/badge/OCA-mail-blue.svg)](https://odoo-community.org/)
[![Powered by Madooit](https://img.shields.io/badge/Powered%20by-Madooit-brightgreen.svg)](https://madooit.com)

## Description

This module integrates WhatsApp messaging into the Odoo mail chatter. It allows sending and receiving WhatsApp messages directly from the chatter interface.

## Installation

1. Clone the module into your Odoo addons path.
2. Update the apps list.
3. Install the "Mail WhatsApp Chatter" module.

Configure your WhatsApp Business API webhook to point to `/whatsapp/webhook`.

## Usage

- WhatsApp messages appear in the chatter with a green badge.
- Use the composer to send WhatsApp messages to partners with mobile numbers.
