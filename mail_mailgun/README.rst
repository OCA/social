Configuration
=============

### Steps to Configure:

1. Go to `Settings > Technical > Email > Outgoing Mail Servers`.

2. Create a New Outgoing Mail Server

3. Set the `Authenticate with` field to Mailgun API.

4. Fill in the Required Fields:

   - Mailgun API Key

   - Mailgun Domain

   - Mailgun API Endpoint

5. Configure system parameter "mail.default.from" and your email alias
