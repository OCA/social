This module gives Odoo an inbox for the messages that the company
receives by several channels (email, WhatsApp...), whatever the channel:

- **Receiving channels**: the email addresses or phone numbers where the
  messages arrive. Each channel is a module (for example
  ``mail_message_import_email`` or ``mail_message_import_whatsapp``).
- **Senders** and their **authorized addresses**: the phones and email
  addresses allowed to send messages on behalf of each sender. A message
  from any other address waits in *Unknown senders* until a person
  assigns it to a sender, and the address can be authorized at the same
  time.
- **Conversations**: the consecutive messages of a sender are grouped
  and processed together once the sender has been silent for some
  minutes, so that clarifications and corrections are read in context.
  The conversations are queued, retried when they fail and reported as
  **incidents** when they keep failing.
- A **panel** with a card per receiving channel: unknown senders,
  incidents, conversations with errors or being processed, and the
  messages of the last days.

The module does not decide what a conversation means: other modules
process them (for example to turn the documents received into orders).
Without one, the conversations are just closed once grouped.

Configuration
=============

1. Give the group *Message Import Manager* to the users that manage the
   application (the administrator has it after the installation).
2. Install the module of a channel (email, WhatsApp...) and create its
   receiving channel in *Message Import > Configuration > Receiving
   channels*.
3. In *Message Import > Configuration > Senders*, create the senders and
   the phones or email addresses they send from, in the tab *Phones and
   email addresses*.
4. In *Message Import > Configuration > Settings*, set the minutes
   without new messages before a conversation is processed, and the
   attempts before it is left in error.

Forwarded Outlook emails (``.msg``) are unpacked when the Python library
``extract-msg`` is installed; standard emails (``.eml``) need nothing
else.

Usage
=====

- *Message Import > Panel* shows a card per receiving channel with what
  is left to review.
- *Message Import > To review > Unknown senders* lists the messages of
  addresses that are not authorized. Select them and press **Assign to a
  sender**: the address can be authorized for the next messages, and the
  messages are processed as a conversation of the sender.
- *Message Import > Received > Conversations* lists the conversations. A
  conversation waiting for more messages can be processed at once with
  **Process now**, and one in error can be processed again with
  **Retry**.
- *Message Import > To review > Incidents* lists what could not be done,
  for example a conversation that failed every attempt. **Retry**
  processes it again once the cause is solved.

For developers, a channel module:

- adds its value to ``mail.message.import.channel.channel_type`` and
  tells the state of its channels in ``_channel_state()``;
- tells how its addresses are compared in
  ``mail.message.import.address._normalize_address()``;
- hands over each message with
  ``mail.message.import.message._receive_message()``.

A module that processes the conversations overrides
``mail.message.import.conversation._process_messages()``, which gets the
messages in chronological order, with their files downloaded and their
forwarded emails unpacked.
