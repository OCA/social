- Go to **Marketing \> Campaigns**.
- Open any campaign and fill in the **Budget Amount** and **Actual Cost**
  fields, under the *Budget* section.
- Values use the company currency automatically.
- These fields are only visible to users with the Sales salesperson group.
- In the campaigns list view, use the optional columns toggle (top right
  of the list) to add **Budget Amount** and **Actual Cost** as columns,
  to compare campaigns without opening each one.
