Social Media Facebook

Integration of the Facebook social network with Odoo Social Media Base module.

This module allows you to:

  • Connect Facebook Pages: Link your Facebook Pages to Odoo
  • Schedule and Publish Posts: Create and schedule posts to Facebook
  • View Statistics: Track post performance with engagement metrics
  • Manage Multiple Pages: Handle multiple Facebook pages from one interface
  • Comment Management: View and respond to comments on your posts

Configuration

Odoo Configuration

  1. Go to Settings > Social Media
  2. In the Facebook App Credentials section:
    • Enter your App ID
    • Enter your App Secret
    • Copy the Redirect URI (you’ll need this for Facebook)

Facebook App Setup

  1. Go to Facebook Developers
  2. Create a new App or use an existing one
  3. Add the following products to your app:
    • Facebook Login (required for authentication)
    • Pages API (required for posting)
    • Webhooks (optional, for real-time lead sync)
  4. In Facebook Login Settings:
    • Add the Redirect URI from Odoo to Valid OAuth Redirect URIs
  5. In Settings > Basic:
    • Copy your App ID and App Secret to Odoo

Connect Facebook Account

  1. Go to Social Media > Media
  2. Select Facebook media type
  3. Click Add Account button
  4. Follow the OAuth flow to authorize the app
  5. Select which Facebook Pages you want to connect
  6. Save the configuration

Lead Ads Webhook Setup (Optional)

For real-time lead synchronization:

  1. In Odoo, go to Settings > Social Media
  2. In the Lead Ads Webhook section:
    • Set a secure Verify Token (use a random string)
    • Copy the Webhook URL
  3. In Facebook Developers:
    • Go to your App > Webhooks
    • Click Add Subscription for Page
    • Paste the Webhook URL as Callback URL
    • Paste the Verify Token (must match Odoo)
    • Click Verify and Save
    • Subscribe to the leadgen field

Note: Your Odoo instance must be accessible via HTTPS for webhooks to work.

Usage

Create and Publish Facebook Post

  1. Go to Social Marketing > Posts > New
  2. In the Post on field, select your Facebook account(s)
  3. Write your message
  4. Add images or videos (optional)
  5. Select a campaign (optional)
  6. Choose when to publish:
    • Now: Publish immediately
    • Schedule: Select date and time
  7. Click Post

View Facebook Posts

  1. Go to Social Marketing > Dashboard
  2. View posts grouped by Facebook page
  3. Each post card shows:
    • Post message and media
    • Engagement metrics (reactions, comments, shares)
    • Post status (Posted, Failed, Posting, Ready)
    • Published time

Manage Facebook Comments

  1. Go to Social Marketing > Dashboard
  2. Click on the comments icon on a post card
  3. View all comments
  4. Reply to comments directly from Odoo
  5. Hide unwanted comments (if you have permissions)

Facebook-Specific Features

  • Reactions: View emoji reactions (👍, 😂, etc.) on posts
  • Shares: Track how many times your post was shared
  • Page Insights: View basic page metrics
  • Multiple Pages: Manage multiple Facebook pages from one Odoo instance
