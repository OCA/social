Configuration
=============

To configure this module, you need to:

#. Create a Facebook App at https://developers.facebook.com/
#. Configure the OAuth redirect URL to: https://your-domain.com/facebook/callback
#. Get your App ID and App Secret
#. In Odoo, go to Social Media > Media and open Facebook
#. Click "Add Account" and enter your credentials

Usage
=====

To use this module, you need to:

#. Go to Social Media > Media
#. Select Facebook and add your page
#. Create posts from Social Media > Posts
